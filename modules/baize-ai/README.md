## Overview

Baize AI is a chat application that leverages advanced AI models to provide interactive and intelligent conversations. It is designed to be user-friendly and highly configurable, allowing users to customize their chat experience.

## Configuration Reference

To configure the Baize AI chat application, you can modify the following parameters in the `app.py` file:

- `title`: The title of the chat application.
- `emoji`: The emoji representing the chat application.
- `colorFrom`: The starting color for the chat interface.
- `colorTo`: The ending color for the chat interface.
- `sdk`: The software development kit used for the chat application.
- `app_file`: The main application file.
- `pinned`: Whether the application is pinned or not.
- `license`: The license for the chat application.

For a comprehensive overview and abstract of the project, please refer to the `README.md` file in the root directory.
